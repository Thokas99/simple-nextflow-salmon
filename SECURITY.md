# Security policy

Security fixes are supported on the latest release and `main`. Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Thokas99/simple-nextflow-salmon/security/advisories/new). Do not open a public issue with exploit details, credentials, confidential paths, or sample data.

This workflow executes user-selected local files and external bioinformatics tools. Review samplesheets and reference sources, pin the workflow revision, and use a least-privilege execution environment.
